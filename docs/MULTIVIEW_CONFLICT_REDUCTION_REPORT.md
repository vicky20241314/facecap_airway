5. **更正上一轮报告的一处表述。** 上一轮把"前置阶段变快"归因于后端改动是错的，见 §7。

## 2. 修了什么：消融与追踪

### 2.1 三处漏点

`identity_views=front` 只挡住了第一处。实际泄漏点：

| 位置 | 原行为 | 泄漏后果 |
|---|---|---|
| `identity_v2.py` 第二次 `solve_field` | 传 `identity`（全部 9 帧） | 软锁/先验解仍用侧面数据 |
| `fit_c.py:278` `refine_shared(...)` | 传 `identity_ids`（全部闭口帧） | 身份局部场由侧面拟合 |
| `fit_d.py` Loop 打分 `probe` | 遍历 `identity`（9 帧） | 曲面候选由侧面数据选 |

修复后三者统一用同一个 `effective_shape_frame_ids`：`fit_c` 的身份相位与 `refine_shared`、
`identity_v2` 的两次求解、`fit_d` 的低/中频场、正则场与 Loop 打分。三个阶段的 `report.json`
都写出该字段，形如：

```
closed_front_0, closed_front_1, closed_front_4          # identity_views=front
closed_front_0/1/4, closed_left_0/2/4, closed_right_1/3/4  # identity_views=all
```

侧面帧仍参与姿态/表情拟合与最终评价——这是任务允许的，也是消融要保留的对照价值。

### 2.2 不变性验证（这是消融可信的前提）

输入扰动：只把 10 个侧面帧的深度整体 +6 mm、标点 z 同步 −6 mm；正面帧逐字节复制。

| 量 | front-only 与 front-only+扰动 的差 |
|---|---|
| 共享 FLAME `shape` (50 维) | **0.000e+00**（逐位相同） |
| 身份局部场 `deviation_m` | 2.08e-8 m |
| 低频场 `deviation_m` | 1.56e-5 m |
| Loop 混合量 | 0.25 vs 0.25（相同） |
| 侧面帧自身位姿 | 允许变化（未约束） |

6 mm 的输入扰动在共享几何上只留下 1.6e-5 m，且身份参数逐位不变。这满足"被排除的观测不得影响
共享几何"的要求；端到端不是逐位相同，差异来源是 `refine_shared` 对侧帧位姿的浮点敏感（2e-8 m）
沿链路的放大，量级上可忽略。

### 2.3 评价工具的训练角色

`eval_multiview.py` 原先把 `reference_split` 成员关系写成 `used_for_shape`，会把消融运行标成
"全部帧参与形状"。现在 `used_for_shape` 取**该 run 自己**的 `identity_selected`，
`role` 由它判定；`multiview.json` 同时保留 `shape_training_frames`（来自第一个 run，用作固定比较划分）
与每个 run 自己的实际训练帧集合。比较划分不变，角色标注可变。

## 3. 约束强度：从命中数量到数据曲率

### 3.1 旧量的两个问题

`np.add.at(information[k], ids, bc)` 累计的是重心命中量。它连续，但：

- 不含方程权重、入射角、局部噪声，因此"25° 掠射的一条射线"和"正射的一条射线"等价；
- 自由集仍靠 `>= 0.5` 的绝对阈值划分，阈值随采样量漂移。

### 3.2 新量

每个顶点沿唯一形变参数（标量法向场）的约束强度，就是加权数据海森的对角元：

```
A[v] = bc · (n_face · d_v)        # 现有方程系数
w_r  = area_quadrature · 连拍权重 · cos²θ · (σ_floor/σ_local)²
I_v  = Σ_r w_r A[r,v]²  =  diag(Aᵀ W A)
```

单位是 1/mm²，即"把该顶点移动 1 mm 会增加多少目标"。实现为 `A².T @ w`，稀疏矩阵一次乘法，
增量开销可忽略。

### 3.3 用连续阻尼承接弱信息

曲率不再做硬切分：`free = (I_v > 0) & ~excluded & ~locked`，只要有数据触及就留在求解里。
抑制弱观测的是锚点先验的强度，按证据连续变化：

```
λ_v = anchor_prior_weight · max(区域强度, clip(I_ref / I_v, 0, 10))
I_ref = median(I_v > 0)
```

中位顶点强度为 1，弱顶点最高 10 倍阻尼，正面覆盖区仍取满强度。这样"求解域随对应微变跳动"
的来源从阈值变成了连续函数——自由集只随"这条射线是否命中"变化，不再随阈值穿越变化。

### 3.4 实测

| 组 | V0 重心计数 | V1 曲率+阻尼 | Δ |
|---|---|---|---|
| 正面闭口留出 | 0.882 | **0.872** | −0.010 |
| 正面闭口训练 | 0.887 | 0.880 | −0.007 |
| 正面张口 | 1.216 | 1.207 | −0.009 |
| 左侧留出 | 0.980 | 0.969 | −0.011 |
| 左侧训练 | 0.884 | 0.878 | −0.006 |
| 右侧留出 | 0.822 | 0.823 | +0.001 |
| 右侧训练 | 0.751 | 0.751 | 0.000 |

自由顶点：低频阶段 1133 → 1187，正则场 1127 → 1167。Loop 候选代价由 1.88240 降到 1.86467

**这份采集上曲率量只值 0.01 mm。** 它换来的是自由集不再由绝对阈值决定；在采样密度变化或

## 4. 正侧冲突：诊断与一次失败的调解

### 4.1 有符号残差（V1，留出闭口帧，单位 mm，正 = 重建面比观测更远）

| 区域 | 正面 | 左侧 | 右侧 | 判读 |
|---|---|---|---|---|
| 下颌/轮廓 | **+0.808** | **−0.863** | +0.182 | 前左**符号相反**，各偏 0.8 mm |
| 口部 | −0.499 | −0.595 | −0.236 | 三视角同号，共同偏差 |
| 鼻部 | +0.020 | −0.163 | −0.163 | 近零，无冲突 |
| 其余面部 | −0.012 | +0.079 | — | 近零 |

冲突是**局部的、方向性的**：只出现在下颌轮廓，且左右要往相反方向推。鼻部与面颊内部没有冲突，
口部是同向的公共偏差。这排除了"侧面观测整体不可靠"的解释——如果侧面是噪声，`face_other`
不会只剩 0.08 mm。

按任务给的三类原因：残差在**轮廓带**集中、内部干净，指向 B（混合深度/局部平面在轮廓处的
失效）与 C（可靠观测提出相反更新）叠加，而不是 A（整片同向偏差）。

### 4.2 用等票权调解：失败，且失败方式可解释

当前 `burst_weights` 给正面 burst 3 倍于单个侧面 burst 的总票权。把它降为等票（`--view-balance`）：

| 组 | 3 倍票权 | 等票权 | Δ |
|---|---|---|---|
| 正面留出 | 0.872 | 0.933 | **+0.061** |
| 左侧留出 | 0.969 | 0.942 | −0.027 |
| 右侧留出 | 0.823 | 0.808 | −0.015 |
| 下颌 正面有符号 | +0.808 | +0.992 | 更差 |
| 下颌 左侧有符号 | −0.863 | −0.762 | 略好 |

冲突没有被消除，只是从侧面搬回正面：正面留出退 0.061，两侧合计进 0.042。**净亏**。
所以 3 倍正面票权不是需要修掉的偏置，它是当前唯一在压制正面轮廓退步的东西。

结论：这一轮的冲突不能靠重新分配视角权重解决。权重是标量，而这个冲突在**轮廓带**上，
需要的是在轮廓处给出更可靠的观测（边缘可靠性、对应有效性），而不是给某个视角更多票。

因此本轮**不**改动融合权重，把它作为下一轮的入口：轮廓处的观测质量，而不是视角配比。

## 6. 候选接受：两处正确性修正

### 6.1 缺失惩罚不再奖励"丢掉高残差射线"

原实现：缺失记 8 mm，而覆盖射线的残差可到 30 mm。于是让一条 25 mm 残差的射线消失，
代价从 625 降到 64，候选得分反而变好。现在覆盖残差在惩罚值处截断：

```
residual = min(|depth difference|, missing_penalty)
```

缺失与最差覆盖射线同价，丢射线不再有收益。这一项没有单独的质量收益数字——它移除的是一个
方向性错误，不是优化。

### 6.2 coverage 预算按视角检查

原来只比全局缺失总数，损失可以集中到一个视角。现在每帧单独设上限：

```
cap_i = max(missing_before_i, baseline_i + max(1, round(0.001 · rays_i)))
per_view_ok = all(missing_after_i <= cap_i)
```

每帧的 before/after/cap 都写进 `line_search_trials`。本采集上正则阶段只有 1 次候选、0 次否决，
所以这项改动在数字上不可见；它在多视角数据上才会起作用。

### 6.3 求解目标与接受目标的口径

`energy()` 现在包含数据项、正则项与先验项，线性化目标与非线性目标用同一函数计算，
不再出现"线性化说更好、刷新后更差"却无法区分的情况。但需要说明：`energy()` 用的是
**冻结对应**的 A、b、rw，它等价于线性化目标；接受判定另用重新求交后的固定射线 MSE。
两者仍是两个不同的量，报告里分开记录（`objective_*` vs `fixed_ray_diagnostic`），
不声称已经统一。

## 7. 更正上一轮报告的两处表述

### 7.1 速度归因

上一轮写"改进后比基线快 22.5%，因为低频不再空转、不必耗 27 次被否决的线搜索"。这个归因不成立：
被否决的线搜索发生在**后端**（dense 阶段），而变快的主要是 `identity_front_anchor`（37.6 → 25.3 s）
等前置阶段——前置阶段的代码与后端 coverage 无关。

本轮同一份代码、不同开关的三次运行，前置阶段耗时是 28.1 / 29.8 / 27.7 s。也就是说
±2 s 是单次运行的波动，上一轮记录的 12 s 差异不能归因于本轮的任何改动。

更准确的说法：**本轮的配置（曲率+阻尼）比上一轮的重心计数配置慢 17 s**（187.6 → 204.9 s），
慢的部分在低频与密集阶段（自由顶点从 1133 增到 1187）。所有耗时都是单次端到端运行，
没有做交错重复，因此不报中位数与区间。

### 7.2 "低频空转"不等于"侧面完全没有贡献"

上一轮写"侧面观测对共享身份没有任何贡献"，依据是低频阶段 `free=0`。这只对**该阶段**成立：
`fit_c` 的 `refine_shared` 与 `fit_d` 的正则场当时仍在用侧面帧。正确的表述是
"低频共享身份阶段空转，`fit_c` 身份参数被冻结"，而不是"侧面数据全程无效"。
本轮把三处都对齐到 `effective_shape_frame_ids`，才使消融具有可解释性。
