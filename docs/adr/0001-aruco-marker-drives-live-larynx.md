# ArUco 标记驱动 live 一键采集的喉结位置

背景：当前默认 C 用 menton + 颈前法向门推断喉结中心，项目已有 ArUco 检测与落盘能力，但没有接入 live 一键采集，也没有进入 C 或下游 `head_windpipe_regis`。我们决定：live `run` 默认要求 closed/open 两态都检出有效 ArUco；自动识别 ID 和黑方块尺寸；标记中心只取高度 t 驱动 C 的喉结先验中心（θ 固定 0，幅度仍由解剖/比例决定）；同一观测以 `anatomical_landmarks.json` 写入最终网格目录；缺失或位置无效时 live 默认失败，只有显式 fallback 才继续并标 not_usable。

**状态**：accepted

**备选方案**：只把标记写 sidecar、不改变 C（重建喉结可能不在标记处）；完全用标记+深度决定位置和幅度（对贴纸/皮肤噪声更敏感）；固定 16 mm ID 0 或操作者手选规格（现场规格会变）。

**后果**：live 采集增加状态结束前的标记门禁和实时提示；尺寸由深度估计，必须记录不确定度；标记驱动可能让 C 的折痕/连接验收变差，按“标记优先，失败如实报告”处理，不自动回退 menton。
