# 离线 loss 优化器：只加记录、分层终止目标、字典序 + 硬约束

背景：主链路里 `fit_c` / `motion_v2` 只持久化每步总量，dense 阶段有固定射线诊断与接受状态，
颈部 `fit_unified` 有每轮能量与目标残差但旧构建未落盘。用户要求：用 loss 分析重建/重塑的
正确性、每时段距终止目标的差距，并据此**离线**优化算法，同时不改变默认算法、标记语义与
验收门。需要一个可重复、可审计、不会用单一加权和掩盖某层退化的方案。

**状态**：accepted

**决定**：

1. **只加记录**：`tools/build_neck_direct_v2.py` 额外写 `loss_direct.json`
   （每轮 `energy` / `energy_parts` / 残差 / remesh pass），不改变求解、参数、接受条件；
   旧运行缺该文件时记为缺口，不反推。
2. **分层终止目标**：基重建（dense 最后一个真实 outer 的固定射线 MSE、缺失射线、接受状态）
   → 颈部连接（两态正向折痕最大值）→ 颈部目标残差（vertex RMS，再 quadrature RMS）
   → 结构与密度（喉结 relief 对参考峰值、上颈带是否加密）。**不跨层相加**。
3. **硬约束先于排名**：标记语义（t/θ/尺寸/状态逐态不变）、保护集、拓扑与两态面表、
   上颈密度、交付 sidecar/manifest 自包含；任一项 fail 或 unverified 的候选不参与排名。
4. **字典序排序**：按上述四层依次比较，低层不能补偿高层。
5. **白名单与预算**：颈部 6 个 + 基重建 3 个参数，单参数单向移动，第一轮最多 12 个候选；
   默认只生成计划，`--execute` 才重跑；候选写入新目录。
6. **每次分析/优化都生成单文件 HTML 报告**：样式与图内嵌、无外链、`null` 不写 0。

**备选方案**：给 `fit_c` / `motion_v2` 插桩拿分项（需要改主代码、复制插桩源码，暂不做）；
把所有分项加权成一个标量 total（违反档位不可加原则，会掩盖固定射线退化）；在线边跑边调
（会改变默认算法与可复现性）；自动应用最优候选（把分析结论直接写回默认参数，越权）。

**后果**：候选重跑昂贵（本次只跑 1 个冒烟），因此第一轮只做单参数移动；旧基线没有目标残差
时只能候选之间比较残差，报告如实标注；下游几何 pass/fail 不属于优化目标，只做输入接口探针；
`fit_c` / `motion_v2` 分项仍是缺口，不反推。
